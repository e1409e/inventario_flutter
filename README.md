# Sistema Modular de Inventarios Multiplataforma

Una aplicación robusta, optimizada y multiplataforma para el control de stock y gestión operativa, desarrollada con Flutter. Diseñada bajo una arquitectura escalable por módulos que facilita su expansión y mantenimiento continuo.

Este sistema ha sido probado en producción, demostrando total fiabilidad y estabilidad operativa al funcionar sin fallas durante meses de uso comercial intensivo, centralizando la información en la nube mediante **Turso**.

## 🚀 Características Principales

* **Arquitectura Modular:** Código estructurado en módulos independientes, lo que permite escalar el sistema y agregar nuevas funcionalidades sin afectar el núcleo de la aplicación.
* **Gestión de Datos en la Nube:** Integración con **Turso (libSQL)** para un almacenamiento centralizado, rápido y confiable, permitiendo sincronización eficiente de los datos del inventario.
* **Soporte Multiplataforma:** Despliegue nativo optimizado para entornos de escritorio (Windows, Linux) y dispositivos móviles (Android).
* **Alto Rendimiento:** Optimización de recursos y consultas para garantizar una respuesta fluida bajo cargas de trabajo exigentes y bases de datos distribuidas.
* **Interfaz Intuitiva:** Diseño enfocado en la usabilidad del usuario final para agilizar los procesos de facturación, control de mercancía y auditoría de stock.

## 🛠️ Tecnologías Utilizadas

* **Frontend & Core:** Flutter, Dart
* **Base de Datos (Cloud):** Turso (libSQL) / SQLite
* **Plataformas Objetivo:** Android, Windows, Linux
